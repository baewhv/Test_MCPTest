# Git 작업 내역 자동 관리 가이드라인 (에이전트 자율 위임)

에이전트는 작업이 완료되면 별도 요청 없이도 변경 사항을 분석하여 자동으로 논리적 커밋을 생성하고 원격 저장소(`origin/main`)에 푸시합니다.

---

## 1. 커밋 메시지 규칙 (Conventional Commits)

```
<type>(<scope>): <간결한 요약>

[본문]
- 상세 변경 내용
- 생성/수정된 Unity 에셋 및 스크립트
```

### Type 목록
- `feat`: 새로운 기능, 컴포넌트, 게임 시스템 추가
- `fix`: 버그 수정, 런타임/컴파일 에러 해결
- `refactor`: 코드 리팩토링, 구조 개선 (기능 변경 없음)
- `style`: 코드 포맷팅, 네이밍 정리, 씬 레이아웃 정리
- `docs`: 문서, 주석, README 수정
- `test`: 유닛 테스트, 통합 테스트 추가/수정
- `chore`: 빌드 설정, 패키지 매니저 종속성, 프로젝트 세팅 수정

---

## 2. 에이전트 자율 Git 실행 절차

1. **상태 점검**: `git status`로 변경 파일 및 `.meta` 파일 누락 확인
2. **논리적 분할 커밋**: 역할별로 파일을 나누어 `git commit` 실행
3. **원격 동기화**: `git push origin main`으로 GitHub 원격 저장소에 즉시 반영
